# k3s-ha — three servers, two agents

An HA k3s cluster: three `k3s.role = "server"` members forming the embedded-etcd
control plane, plus two agents. This is the template that exercises the converge
ordering contract end to end.

Generated by:

```bash
nix flake init --template github:kitsunoff/nixcluster#k3s-ha
```

## Layout

```text
flake.nix                          flake-parts + import-tree + nixcluster
modules/
  base.nix                         the NixOS base every member inherits
  clusters/k3s-ha.nix              cluster options (which modules, which base)
  nodes/server-{1,2,3}.nix         control plane
  nodes/agent-{1,2}.nix            workers
```

## Converge order

`converge` is a dependency graph, not a fixed pipeline. Roles in the node files
are all it takes to produce this:

```text
member-server-1 ──┬──> member-server-2 ──┐
                  ├──> member-server-3 ──┼──> member-agent-1
                  │                      ├──> member-agent-2
                  └──────────────────────┴──> k3s.bootstrap
                                              k3s.kubeconfig
```

- `server-1` (first server by name) bootstraps etcd, so `server-2` and `server-3`
  depend on it — and on nothing else, so they are not serialised behind each other.
- Each agent depends on **all three** servers: there is no control plane to join
  until they are up.
- `k3s.kubeconfig` depends on the servers only — an agent is irrelevant to it.

Check it yourself, without installing anything:

```bash
nix eval .#clusterConfigurations.k3s-ha.convergeOrder
nix run .#cluster-k3s-ha -- converge --dry-run
```

A step whose dependency did not succeed is **skipped**, not run — a failed
bootstrap does not drag the agents through a pointless join attempt.

## What to change

| Where | Field | Why |
| --- | --- | --- |
| `modules/nodes/*.nix` | `install.ip` | the address converge connects to |
| `modules/nodes/*.nix` | `install.disk` | the disk the installer wipes — check it |
| `modules/nodes/*.nix` | `k3s.role` | move a node between control plane and workers |
| `modules/base.nix` | `users.users.root.openssh.authorizedKeys.keys` | the key converge authenticates with |
| `modules/base.nix` | `boot.loader.grub.device`, `fileSystems."/"` | must match the real disk |
| `modules/base.nix` | `nixpkgs.hostPlatform` | `x86_64-linux` for x86 nodes |
| `modules/clusters/k3s-ha.nix` | the cluster name `k3s-ha` | names the CLI app and the NixOS configurations |

> [!IMPORTANT]
> Keep the server count **odd** (3, 5, …). Embedded etcd needs a majority to
> elect a leader; four servers tolerate no more failures than three.

> [!WARNING]
> First-time installation runs `nixos-anywhere`, which **wipes the target disk**.
> Verify every `install.ip` and `install.disk` before converging.

## Use it

```bash
nix run .#cluster-k3s-ha -- converge --dry-run   # plan only
nix run .#cluster-k3s-ha -- converge             # install/switch, then kubeconfig
nix run .#cluster-k3s-ha -- k3s nodes            # after the kubeconfig is fetched
```

Adding a server is one file: copy `server-3.nix` to `server-4.nix`, change the
name and IP, and the plan updates itself. (Keep the count odd.)
